# Engineering Principles

## 1. Simplicity First

Choose the simplest solution that satisfies the requirements.

---

## 2. Configuration Over Hardcoding

Business rules belong in configuration whenever practical.

---

## 3. Single Responsibility Principle

Every module should have one clear responsibility.

---

## 4. Type Safety

Use Python type hints throughout the project.

---

## 5. Testability

Every important module should be unit testable.

---

## 6. Observability

Everything important should produce useful logs.

---

## 7. Idempotency

Running the same process twice should not corrupt data.

---

## 8. Documentation

Architectural decisions must be documented.

---

## 9. Security

Secrets must never be committed to Git.

---

## 10. Automation

Anything done repeatedly should be automated.
